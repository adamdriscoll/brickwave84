# Brickwave '84 — Synthwave Background Music Loops

Three loopable background tracks for an 1980s retro arcade / synthwave Breakout-style game.

## Tracks

1. `01_neon_grid_cruise_loop_96bpm.wav`
   - Vibe: menu, early levels, chill arcade attract mode
   - Tempo: 96 BPM
   - Loop length: 16 bars
   - Usage: title screen, level select, lower-pressure gameplay

2. `02_brick_blaster_drive_loop_112bpm.wav`
   - Vibe: main gameplay, energetic but not overwhelming
   - Tempo: 112 BPM
   - Loop length: 16 bars
   - Usage: standard gameplay loop

3. `03_chrome_sunset_overdrive_loop_124bpm.wav`
   - Vibe: late-game, hard levels, boss/challenge mode
   - Tempo: 124 BPM
   - Loop length: 16 bars
   - Usage: special levels, high score chase, intense runs

## Unity import suggestions

- Import as WAV during development.
- Set Load Type to `Streaming` for music.
- Enable Loop in the Audio Source.
- Start music around 0.25–0.4 volume and tune against SFX.
- Keep brick / paddle SFX on a separate mixer bus from music.

## Notes

Designed to loop cleanly and stay in the same sonic family as the Brickwave '84 synthwave SFX pack:
- saw / square synth bass
- bright arpeggios
- gated-style retro drums
- short melodic hooks
- no vocals, no long intros
