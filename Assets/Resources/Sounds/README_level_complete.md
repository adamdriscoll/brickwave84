# Brickwave '84 – Level Completion SFX

## File

- `level_complete_stage_clear_neon_fanfare.wav`

## Intent

A short synthwave “stage clear” flourish for when the final brick is cleared or the level transition begins. It uses a rising arpeggio, bright chord hit, bass resolve, and small sparkle tail.

## Unity Suggestions

- Play once through a UI / game-state audio source, not the ball collision source.
- Suggested volume: `0.75–0.9` depending on music level.
- Avoid random pitch variation for this one; it should feel like a recognizable reward cue.
- Consider briefly ducking the music by 2–4 dB while it plays.
- Trigger before level summary / next-level animation.

## Optional Variants To Add Later

- A shorter “perfect clear” sting.
- A darker “level failed” sting.
- A longer final-stage clear fanfare.
